# 04: Predictive world models

**Status: planned, not started.**

The goal is to replace the simulator with a learned model: predict future states in a latent space, then plan movements against those predictions before executing anything. Module 01 calls MuJoCo for every step, and this module is about not needing it.

Planned contents:

- A predictive dynamics model that works in latent space
- Planning inside the learned model before acting

Nothing in this folder runs yet. Commands and results will go here once there are some.
